Phân quyền tập trung (convert Sys_Access): role / permission / grant / assign + check API cho cả fleet. Mô hình ALLOW: chưa grant = chặn.

  • POST/GET /api/roles · POST/GET /api/permissions
  • POST /api/roles/{code}/grant|revoke
  • POST /api/users/{user}/assign|unassign · GET /api/users/{user}/permissions
  • GET /api/check?user=&permission= → allowed
